右键即达的工具集

每一项都可以在设置里单独开关；所有逻辑在你的浏览器本地执行。

📷

二维码生成

选中的文字、当前页面、任意链接一键生成二维码，支持下载 PNG 与复制图片。

🔍

二维码识别

右键图片自动下载解码（jsQR），结果直接复制；是链接可一键跳转。本地图片可到工具页上传识别。

🖼

以图搜图

百度识图与谷歌 Lens 双通道，右键图片直达相似图搜索。

⬇️

下载推送

一键推送到 Aria2 / Motrix（自动附带 Referer 与站点 Cookie），也可交给浏览器下载。

🔒

密码与 Cookie

明文显示页面密码框（可还原）；Cookie 支持请求头 / Netscape / JSON 三种格式导出。

🛡

代理管理器

固定服务器、PAC 订阅、域名分流三种模式，弹窗一键开关，随时查看出口 IP。

🌐

网盘聚合搜索

选中资源名右键直达搜索引擎，URL 模板完全自定义。

🧩

自定义脚本

把常用 JS 保存为右键菜单项，在任意页面一键执行。

📦

开箱即用

无远程应用商店、无统计埋点 —— 那正是原版集装箱停服的根源，我们把它彻底去掉。

三分钟完成安装

适用于 Chrome、Arc、Edge 等所有 Chromium 内核浏览器。

下载并解压到 Releases 下载最新 zip，解压到一个长期保留的目录。
打开扩展管理页地址栏输入 chrome://extensions，打开右上角「开发者模式」。
加载扩展点击「加载已解压的扩展程序」，选择解压出的文件夹。
开始使用在任意网页点击右键，即可看到阿苏工具箱的全部菜单；工具栏图标里有快捷面板与设置入口。

常见问题

更多问题请到 GitHub Issues 提问。

右键菜单没有出现？

确认扩展已启用、设置里对应菜单项已打开；仍不出现就到扩展管理页点「重新加载」。

识别图片二维码失败？

防盗链图或跨域受限图无法直接下载解码。可先另存图片，再在「二维码工具」页上传识别。

推送到 Aria2 / Motrix 失败？

九成是服务未启动或 RPC 地址/密钥不一致。Motrix 请在「设置 → 进阶」确认端口与密钥。

和原「集装箱」是什么关系？

没有关系、无代码关联。原版远程应用商店后端已于 2026 年停服，本项目的哲学是功能内置、一切本地。
