阿苏工具箱 · 设置

右键菜单开关

关闭的项不会出现在右键菜单里。

Aria2

Motrix

网盘聚合搜索

选中文字后右键搜索网盘资源。URL 模板里用 {q} 表示关键词。原大力盘若失效可换成任何网盘搜索引擎。

以图搜图

图片右键直达。百度接口按图片 URL 提交，防盗链图可能失败（用谷歌 Lens 更稳）。两个菜单的开关在「右键菜单」页。

代理管理

提供通用代理能力：固定服务器 / PAC 订阅地址 / 域名分流规则。

自定义脚本

右键页面 →「▶ 脚本名」执行。脚本在页面上下文（MAIN world）运行，受站点 CSP 限制。复杂的注入需求建议用篡改猴 / 脚本猫。

备份 / 恢复

全部设置以 JSON 导出，换机或重装后可一键恢复。
